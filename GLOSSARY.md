# Glossary

- **Conversation:** An owner's record of a learner question, its answer, and any optional learning offer. A conversation can exist without a journey.
- **Learning offer:** An optional proposal to create a learning journey. Dismissing an offer does not create learning content.
- **Consent:** The owner's explicit acceptance of a displayed goal, study-session target, and daily activity-time budget.
- **Journey:** A private, owner-scoped learning plan created only after consent. Its target counts study sessions, not calendar days.
- **Session:** One planned learning unit within a journey. Only session 1 is reserved at acceptance; later sessions require a separate explicit continuation.
- **Source manifest:** The allowlisted set of sources supporting a session, including retrieval and lesson relationships; it is not arbitrary source text.
